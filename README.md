# BigPicture Sweden website (deprecated)

This site has been retired. Bigpicture now lives at
<https://portal.bigpicture.eu>.

The only thing published from this repository is a redirect page
(`site/index.html`), which is also served as `404.html` so every old URL on
bp.nbis.se forwards to the new portal. The previous Quarto sources are
available in the git history.
